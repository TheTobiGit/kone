# Rune actions audit

Scope: launcher/start and Create/Open/Clone, projects list, project Overview, and Studio. Compared Electron `dev` at [`b6886c16`](https://github.com/TheTobiGit/kone/commit/b6886c166e591fb0d8c3f747ccee02e370dd5f6e) with Rune `feat/rune-port` at [`3b0e9f5a`](https://github.com/TheTobiGit/kone/commit/3b0e9f5a79a87c93461c12a60c394f2ac657c3c5). Settings, Git, Space, Files, Inbox, Bench and other portals are **OUT-OF-SCOPE**. Visual-only differences do not count as action gaps.

**IMPLEMENTED** means the named effect is wired; **PARTIAL** means an in-scope path or behavior differs; **MISSING** means the effect is absent. The summary counts grouped action rows, not individual controls. Status is based on source and linked verification, not a new live test pass.
